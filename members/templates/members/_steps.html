{# ログイン直後に「次に何をすればいいか」が分かるようにするための手順。 #} {# members / rounds の有無で、完了・実行中を切り替える。 #}
  1. 1

    メンバーを登録する

    一緒に行く人の「名前・最寄り駅・車を出せるか」を登録します。 登録するのは最初の1回だけで、次からは選ぶだけです。

    {% if not members %} メンバーを登録する {% endif %}
  2. 2

    おでかけを作成する

    「おでかけ」は、みんなで車移動する予定1回分のことです。 日付と行き先を決めて、参加する人にチェックを入れ、運転手の集合時刻を入力します。

    {% if members and not rounds %} おでかけを作成する {% endif %}
  3. 3

    配車を計算する

    おでかけの「配車を計算」を押すと、参加者の最寄り駅から運転手の駅までの電車の所要時間を調べ、 全員の合計がいちばん短くなる組み合わせを決めます。

    {% if rounds %} おでかけ一覧へ {% endif %}
