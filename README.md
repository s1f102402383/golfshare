# 配車プランナー

## 概要
車を出せる人と乗せてもらう人を、最寄り駅と乗車可能人数から自動でマッチングするWebアプリです。
所属するゴルフ部で毎回の配車決めに困っていた課題から着想し、部活動に限らず旅行やイベントなど幅広い場面で使えるように設計しました。

## 機能
- メンバー登録・管理（最寄り駅・車の有無・乗車可能人数）
- おでかけ作成（日付・参加メンバー・集合駅・集合時間）
- 配車の自動最適化（移動時間・乗車可能人数を考慮）
- ユーザーごとのデータ管理

## 使用技術
- Python / Django
- PostgreSQL
- Docker
- Render（デプロイ）
