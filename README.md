# GolfShare - ゴルフ部カーシェア最適化アプリ

## 概要
ゴルフ部のラウンド時に、車を持っている部員と持っていない部員を最適に配車をマッチングするWebアプリです。
実際に所属するゴルフ部で困っていた課題を解決するために開発しました。

## 機能
- 部員登録・管理
- ラウンド作成（参加メンバー・集合駅・集合時間）
- 配車の自動最適化（移動時間・乗車定員を考慮）
- ユーザーごとのデータ管理
## 使用技術
- Python / Django
- PostgreSQL
- Docker
- Render（デプロイ）
- GitHub
